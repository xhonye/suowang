所往 SUOWANG · Windows 使用说明
================================

开始使用
--------
1. 双击“所往 SUOWANG”或桌面上的“所往 SUOWANG”图标。
2. 稍等片刻，所往会在默认浏览器中自动打开。
3. 第一次使用时会在本机创建自己的数据文件；不需要注册、联网或安装 Node.js。

你的数据
--------
数据、自动备份和日志保存在 Windows 的本机应用数据目录，程序卸载时不会删除它们。
新安装默认使用 %LOCALAPPDATA%/SUOWANG。旧版若已经在 D:/5Data/suowang 存在 suowang.db，会继续使用旧目录且不会自动搬迁。
如果两个位置都存在数据库，所往会停止并列出两个路径；请通过 SUOWANG_DATA_DIR 明确选择，不要手工合并运行中的数据库。
请在“设置”中使用导出功能自行保存一份备份。

手机访问
--------
默认只允许本机访问。只有你在设置中明确启用 Tailscale 后，手机才可通过同一 Tailnet 访问。

遇到 Windows 安全提示
--------------------
请只从所往的官方 GitHub Release 下载。首次运行新版本时，Windows 可能会询问确认；确认发布页面和文件名无误后再继续。
