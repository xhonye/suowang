所往 SUOWANG · Windows 使用说明
================================

0.2.0-beta.3 是公开体验版本，可能仍有未发现的问题。升级或开始测试前，请先在“设置”中导出一份 SQLite 备份；不要把数据库或私人事项作为反馈附件发送。

选择哪个版本
------------
轻量版（推荐）：双击“所往 SUOWANG（轻量版）”，无终端窗口，在默认浏览器打开；不需要自行安装 Node.js。
桌面版：双击“所往 SUOWANG”，在独立应用窗口打开；内置 Electron/Chromium，所以体积更大。

两版功能和数据相同，共用 Windows 本机数据目录。不要同时打开两版；实例锁会拒绝第二个入口以保护 SQLite。

Portable ZIP 必须先完整解压。轻量版双击 SUOWANG-Lite.exe，桌面版双击 SUOWANG.exe；不要直接在压缩包中运行。

你的数据
--------
数据、自动备份和日志保存在 Windows 的本机应用数据目录，程序卸载时不会删除它们。
新安装默认使用 %LOCALAPPDATA%/SUOWANG。旧版若已经在 D:/5Data/suowang 存在 suowang.db，会继续使用旧目录且不会自动搬迁。
如果两个位置都存在数据库，所往会停止并列出两个路径；请通过 SUOWANG_DATA_DIR 明确选择，不要手工合并运行中的数据库。
请在“设置”中使用导出功能自行保存一份备份。自动备份与原数据库位于同一设备，不等于异地灾备；重要数据请另外保存到另一设备或可信同步位置。

手机访问
--------
默认只允许本机访问。只有你在设置中明确启用 Tailscale 后，手机才可通过同一 Tailnet 访问。

遇到 Windows 安全提示
--------------------
请只从所往的官方 GitHub Release 下载。首次运行新版本时，Windows 可能会询问确认；确认发布页面和完整文件名无误后再继续。

报告启动问题
------------
请提供安装文件的完整文件名、Windows 版本、错误窗口中的“阶段”和“原因”，以及日志目录中最新日志；不要发送 suowang.db、备份或私人事项。
