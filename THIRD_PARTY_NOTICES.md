# Third-party notices

The self-contained Windows and macOS distributions include the following runtime components:

- Electron `44.0.0`, including Chromium and Node.js, under their respective
  open-source licenses. Electron and Chromium license notices are included in
  the Desktop and macOS applications generated by Electron Forge.
- The Windows Lite distribution includes the official Node.js `24.15.0`
  Windows x64 runtime. Its upstream archive is verified against nodejs.org
  `SHASUMS256.txt`, and its license is included as `runtime/NODE-LICENSE.txt`.
- `better-sqlite3` `13.0.3`, MIT license. Its complete license file is included
  in `node_modules/better-sqlite3/LICENSE`.
- `node-addon-api` `8.9.2`, MIT license. Its complete license file is included
  in `node_modules/node-addon-api/LICENSE.md`.

SUOWANG itself is distributed under the Apache License 2.0; see `LICENSE`.

Source development, packaging and automated tests additionally use:

- `@playwright/test` `1.62.1`, Apache License 2.0. This dependency is not
  included in the end-user Windows or macOS application payload.
- Electron Forge `7.11.2` and its ZIP, DMG, native-unpack, fuses and packaging
  components. These are build-time tools and are not separately installed on
  end-user systems.
- `@electron/rebuild`, `@electron/notarize`, Electronegativity, `sharp` and
  `png-to-ico` as release engineering tools.

The npm lockfile is the exact dependency inventory for source builds. Release
packages include the runtime components selected by the Forge package manifest.
