# SUOWANG Logo 统一与界面精修计划

日期：2026-09-07。状态：已按用户后续授权完成本地实现与正式 Desktop 安装更新，视觉效果待用户实际使用反馈；未公开发行。用户要求：当前 Logo 用到快捷方式，同时优化界面效果，先规划；后续明确「统一山水道路 Logo，实施计划」。

## 目标与方向

从桌面入口到应用内，使用同一套山水道路品牌形象。界面方向为「晴朗、安静、方向清楚」：道路负责环境与识别，当前主线负责定位，下一步负责行动，其余控件降低视觉重量。

沿用三模式、三主线槽和现有驾驶流程。保留批准道路底图、箭头、构图关系与工作区空间四档；本轮不调整业务模型或数据。

## 已核实的现状

- 仓库：`suowang`，分支 `main`；规划写入前工作树干净。
- `index.html` 与 `docs/handoff.md` 当前指定的品牌图是 `assets/brand/suowang-scenic-mark-v1.png`，已查看原图。
- `scripts/build-icons.mjs` 仍从旧圆环箭头 `suowang-app-icon.svg` 生成 ICO、PNG、favicon 和 macOS ICNS；单独改快捷方式不能解决下次构建重新变回旧图的问题。
- Lite EXE 编译、Electron 打包、安装器、窗口图标已接入上述旧图标产物。安装器桌面与开始菜单快捷方式引用 EXE 内嵌图标。
- `scripts/install-shortcut.ps1` 的源码快捷方式直接使用 `shell32.dll,18` 系统图标。
- 本机两个桌面入口分别指向用户安装目录与仓库内历史试装目录，需要在实施时核实有效目标并逐个处理，不能只凭名称覆盖。此轮仅读取快捷方式属性，未启动或修改安装。
- 当前山水 Logo 原图外缘可见少量杂边，缩小后的边缘和有效占幅需要专项检查。
- CSS 已有多轮覆盖规则；文字层级、圆角、阴影和交互状态的统一应依据最终生效样式完成，避免继续无序追加。

本轮已检查代码、品牌图片和快捷方式配置；未启动真实页面或读取个人业务数据。下面的界面建议是设计方案，最终尺寸和效果由隔离预览验证。

## 一、Logo 与 Windows 入口统一（优先）

1. 以当前山水道路 Logo 为品牌母版，保留原图。检查透明边缘、图形居中和安全留白；必要的修边使用新文件名，先看浅色与深色背景预览。
2. 统一构建来源，派生 Windows 多尺寸 ICO、窗口 PNG 和 favicon；同步现有 macOS 生成链路，避免平台间继续使用两套形象。
3. ICO 检查 16、32、48、64、128、256 像素各层；大尺寸保持山水层次，小尺寸优先保证道路轮廓可识别。若确需简化小图，作为同一 Logo 的适配稿单独预览。
4. 接通源码快捷方式、Lite 启动器、Desktop EXE、安装器及开始菜单。升级已有入口时保留目标程序、参数和工作目录，先核实安装类型；旧试装入口是否保留单独列明，不自动清理。
5. 验证桌面、开始菜单、文件资源管理器及 Desktop 任务栏图标。Lite 打开默认浏览器，应用品牌覆盖快捷方式和浏览器标签页，浏览器自身任务栏身份仍由浏览器管理。

交付：统一品牌源及派生文件、更新后的图标生成链路、入口覆盖清单和本机验证记录。不能以仓库文件已更新代替已安装 EXE 或旧快捷方式已更新。

## 二、界面精修

| 区域 | 拟调整 | 用户应感受到的结果 |
| --- | --- | --- |
| 左栏品牌与导航 | 校准 Logo 的实际可见大小、与中英文名称的基线和间距；减轻外围阴影；统一导航图标线宽与选中底色 | Logo 清楚，导航整齐，品牌区不显挤 |
| 天空文字 | 拉开问候、标题、日期和 Cue 的主次；降低英文装饰和解释性文字的存在感；校准左右对齐 | 道路更舒展，文字易读且不抢模式入口 |
| 三个主线槽 | 统一高度、内边距、圆角和更多按钮位置；收敛悬浮阴影；以边线和浅底强调当前主线 | 一眼找到当前主线，另外两条仍易于选择 |
| 主线详情 | 次要标签轻量但保持可读，正文适当提高字号和对比；统一分隔线及编辑焦点 | 目标和完成标准更易扫读，原地编辑更明确 |
| 下一步 | 强调事项名称与「开始这一步」；最小一步作为第二层；理顺暂停、完成和「卡住了？」的权重 | 视线更快落到现在可以做的动作 |
| 事项列表 | 校准行高、名称与最小一步间距、完成按钮与添加区对齐；统一 hover、编辑、拖动落点反馈 | 更好读、更容易点，操作时不跳动 |
| 行迹、设置与弹层 | 沿用同一套标题、表单、按钮、分隔线、空状态与错误反馈样式 | 三个页面像同一个产品，低频操作同样清楚 |

视觉参数先在预览中收敛：灰蓝强调色、雾白底色、深灰蓝正文；正文以 13–14px 为起点，关键行动标题以 18–20px 为起点，辅助信息尽量避免 8–9px；以 4/8px 间距步进和少量圆角档位统一控件。这些是候选参数，不能为满足数值而挤压道路、造成溢出或拉高下一步卡。

保留明显键盘焦点、非颜色状态提示和减少动态效果支持。动效仅服务于状态变化，下一步出发动效继续限制在卡片内。

## 实施顺序与验收

1. **隔离预览**：新建独立预览文件，使用虚构数据展示驾驶舱、行迹、设置的代表状态；同时展示 Logo 在桌面常用尺寸和深浅背景下的效果。受保护的 `docs/visual-final-preview.html` 保持原样。
2. **审阅后接入**：先完成图标链路，再按左栏／主线／下一步／事项顺序落实批准的视觉。只整理本轮涉及的 CSS，避免整文件重写。
3. **页面验证**：临时数据目录、非默认端口下检查 1920×1080、2560×1440、320px，补充矮窗与 125%/150% 缩放观察；覆盖三模式、空数据、长文字、长列表、编辑及「卡住了？」展开。确认页面可滚到底、无横向溢出、下一步高度稳定。
4. **图标与打包验证**：检查源图到产物一致性、ICO 多尺寸、实际 EXE 图标、安装与升级后的快捷方式，再核对 Desktop 运行图标。新增聚焦的回归检查，防止构建重新生成旧 Logo。
5. **交付**：提供前后对照、变更清单及验证结果；区分代码检查、真实系统图标显示和用户视觉验收。公开发行另按既有发行流程执行，本计划不代表发布授权。

## 本地实施结果

- 山水道路原图逐字节保留，图标仅进行尺寸转换。界面、favicon、Windows 六尺寸 ICO 与窗口 PNG 已统一；旧 SVG 保留为历史文件，不再参与构建。macOS 分支共用新来源，本机没有执行 macOS ICNS 构建或安装验收。
- 原位调整既有 CSS：品牌留白、文字字号与对比度、主线选中层级、阴影、表单及按钮统一；道路底图与箭头没有改动。补充长文本检查发现操作按钮会被挤出卡片，已使文字区域内部滚动并固定操作区。
- 本机两个桌面快捷方式和一个开始菜单入口均已更新图标，目标、参数等属性回读一致；再次运行更新脚本修改数为 0。备份留在本机应用数据目录的 `brand/shortcut-backups/` 下。
- 标准 Desktop 安装仅替换实际不同的 `SUOWANG.exe` 与 `resources/app.asar`，两项均先备份并核对哈希。桌面 **SUOWANG** 入口已使用新版界面。名为 **所往 SUOWANG** 的历史试装入口保留旧程序目标，仅更新快捷方式图标。
- 标准安装的隐藏窗口 smoke 使用临时数据库，验证 renderer、数据库写入及四张道路资源真实解码；没有使用个人数据库验证。安装回滚备份在本机应用数据目录的 `application-backups/` 下，精确路径见下方本地记录。
- Lite 启动器已独立重新编译并从实际 EXE 提取图标，与 Desktop 提取图标均确认是山水道路。Lite 完整安装／升级和 macOS 安装未在本轮执行；不能将这些结果当作公开发行验收。

### 快捷方式空白图标补修

用户随后反馈桌面显示空白文件图标。现场核对快捷方式目标、ICO 路径和文件哈希均有效，Windows `SHGetFileInfo` 从快捷方式、ICO 和 EXE 均能读取山水 Logo；这支持桌面显示缓存未刷新的判断，但程序内提取成功不能替代桌面显示验收。

`refresh-shortcut-icons.ps1` 已补充逐项 `SHCNE_UPDATEITEM` 同步通知：路径和哈希未变时仍刷新 Explorer 对该项目的显示；图标丢失或损坏时重新复制母版产物。此修补执行时更新文件 0 项，定向刷新 2 项（当前有效桌面入口和开始菜单入口）。没有重启 Explorer 或清空全局图标缓存。修改后的 Shell 图标回读正常，桌面最终显示仍以用户现场反馈为准。
