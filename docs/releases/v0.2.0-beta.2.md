# SUOWANG 0.2.0-beta.2 · Visual Asset Hotfix

这是 `0.2.0-beta.1` 的桌面发行热修复。Beta.1 的 Electron 包遗漏了道路底图与三张箭头层；业务数据和交互仍可运行，但产品的签名视觉无法显示。Beta.2 保持数据模型、数据库 schema 和批准视觉资产逐字节不变，只修复打包与验收门禁。

## 推荐下载

Windows 用户优先下载：

- `SUOWANG-Setup-0.2.0-beta.2.exe`：双击安装，桌面图标启动；无需 Node.js 或命令行。
- `SUOWANG-Portable-0.2.0-beta.2.zip`：免安装备用；解压后双击 `SUOWANG.exe`。

Apple Silicon Mac 可下载 `SUOWANG-0.2.0-beta.2-mac-arm64.dmg`。macOS 当前属于实验支持，应用未签名、未公证，首次打开可能需要按住 Control 点击应用并选择“打开”。

请同时下载对应 SHA-256 文件核对完整性。第三方网盘只能镜像本 Release 中文件名和 SHA-256 完全一致的资产。

## 本次修复

- 修复 Forge 在 `assets` 根目录提前停止遍历，导致四张批准道路视觉资产没有进入 `app.asar`。
- 候选验证现在直接检查四张资产存在于 `app.asar` 且非空。
- 真实 packaged smoke 会在 Electron renderer 内等待四张图片完成解码，并核对每张尺寸均为 `2172×724`。
- 视觉资产清单成为打包、ASAR 验证和 renderer 解码验证共用的单一真源。

## 隐私与升级

- 本地优先，无账号、无云同步、无遥测、无运行时 AI。
- Beta.2 不改变数据库 schema；从 Beta.1 或更早版本升级会继续使用原本地数据。
- 升级前仍建议在设置中导出 SQLite，并将重要备份保存到另一设备或可信同步位置。
- 不要上传数据库、备份、私人事项、Token 或未脱敏截图作为反馈。

## 已知限制

- Windows 与 macOS 安装包尚未进行商业代码签名，系统可能显示来源警告。
- macOS 只支持 Apple Silicon，不支持 Intel Mac，未上架 App Store。
- 没有自动更新、账号、云同步或多设备冲突合并。
- Public Beta 不应成为重要数据的唯一副本。
