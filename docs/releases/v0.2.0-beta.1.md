# SUOWANG 0.2.0-beta.1 · Public Beta

这是首个面向陌生用户的公开体验版本。它以可靠性冻结线为基线，没有扩张产品模型；重点是让普通用户能够安装、保留本地数据并安全反馈问题。

## 推荐下载

Windows 用户优先下载：

- `SUOWANG-Setup-0.2.0-beta.1.exe`：双击安装，桌面图标启动；无需 Node.js 或命令行。
- `SUOWANG-Portable-0.2.0-beta.1.zip`：免安装备用；解压后双击 `SUOWANG.cmd`。

Apple Silicon Mac 可下载 `SUOWANG-0.2.0-beta.1-mac-arm64.dmg`。macOS 当前属于实验支持，应用未签名、未公证，首次打开可能需要按住 Control 点击应用并选择“打开”。

请同时下载对应 SHA-256 文件核对完整性。第三方网盘只能镜像本 Release 中文件名和 SHA-256 完全一致的资产。

## 隐私与运行边界

- 本地优先，无账号、无云同步、无遥测、无运行时 AI。
- 主线、事项、头像和设置默认只保存在本机 SQLite 数据库与本地数据目录。
- 默认只监听 `127.0.0.1`；可选 Tailscale 访问只适用于你信任的同一 Tailnet 设备。
- 应用不会自动上传反馈、日志或数据库。

## 升级前备份

如果你已经使用旧版，请先在设置中选择“导出 SQLite”，把文件保存到另一设备或可信同步位置。自动每日备份通常和原数据库在同一设备，不能替代异地副本。

## 主要变化

- 增加「开始这一步 / 暂停」行动指针，不做计时、专注统计或行为日志。
- 持续事项每天最多记录一次，保留累计事实，不引入连续打卡、提醒、积分或惩罚。
- 加固 migration、每日备份、SQLite 导出与整库恢复的完整性和原子性。
- Windows/macOS 启动器统一验证版本、进程身份、端口与数据目录。
- 候选资产由同一个完整 commit SHA 构建；Release 发布前复验双平台校验和与人工安装证据，已发布资产禁止覆盖。

完整变化见 [CHANGELOG.md](https://github.com/xhonye/suowang/blob/v0.2.0-beta.1/CHANGELOG.md)。

## 已知限制

- Windows 与 macOS 安装包尚未进行商业代码签名，系统可能显示来源警告。
- macOS 只支持 Apple Silicon，不支持 Intel Mac，未上架 App Store。
- 没有自动更新、账号、云同步或多设备冲突合并。
- Tailscale 模式没有额外的应用账号认证，不应暴露到公网。
- Public Beta 可能仍有未发现的问题，不要把 SUOWANG 当作重要数据的唯一副本。
