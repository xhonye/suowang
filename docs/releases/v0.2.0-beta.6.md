# 所往 SUOWANG 0.2.0-beta.6

保存遇到问题，刚写下的内容会留在原处。

- 原地修改失败时保留草稿和键盘焦点，可以直接修正后重试。Enter 保存、Escape 取消后返回原位置；中文输入法选字不再提前提交。
- 确认弹窗保存成功才关闭，出错时在弹窗里说明原因；修复按 Enter 意外关闭弹窗的问题。
- 从其他模式的行迹复制主线，以及恢复备份后，驾驶舱会显示对应模式。
- 本地服务暂时断开时显示清楚的中文提示。

Windows 推荐 **SUOWANG-Lite-Setup-0.2.0-beta.6.exe**，独立窗口可选 Desktop Setup。macOS Apple Silicon 使用本页 DMG。

本版不改变数据模型或备份格式。数据仍在本机；升级前可在设置导出 SQLite 备份。Lite 与 Desktop 共用数据目录，不能同时打开。仍为未签名／未公证的公开测试版。
