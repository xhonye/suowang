# SUOWANG 0.2.0-beta.3

这是一次以 Windows 使用便利性和桌面自适应为重点的公开 Beta。

## Windows 下载

普通用户推荐：

- `SUOWANG-Lite-Setup-0.2.0-beta.3.exe`：双击安装，桌面图标启动；无终端窗口，在默认浏览器打开，不需要安装 Node.js。

偏好独立应用窗口：

- `SUOWANG-Desktop-Setup-0.2.0-beta.3.exe`：双击安装，直接打开无地址栏的独立窗口；因为内置 Electron/Chromium，文件明显更大。

两版功能与本地数据相同。它们使用不同安装目录和快捷方式，但共用同一个 SQLite 数据目录；不要同时打开，第二个入口会被实例锁拒绝。Portable ZIP 只作为免安装备用，必须先完整解压。

## macOS

- `SUOWANG-0.2.0-beta.3-mac-arm64.dmg`：仅支持 Apple Silicon（M1 及以后）。拖入 Applications 后打开。

当前公开 Beta 未签名、未公证。Windows 或 macOS 首次运行可能要求确认来源；只从本 Release 下载，并核对 SHA-256。

## 本版变化

- Windows 增加不携带 Chromium 的 Lite 自包含版，同时保留 Electron Desktop 版。
- Lite 使用原生无控制台启动器和已校验的官方 Node 运行时，双击后不会弹出 PowerShell/命令行窗口。
- 道路舞台按窗口宽高共同适配；2560×1440 最大化时主视觉不再反向变矮。
- 大窗口只延展主线事项与其他事项列表，下一步卡保持紧凑高度。
- 左侧品牌换成透明道路景观标识，个人区域同步降噪。
- 候选门禁覆盖四个 Windows 发行物、两个真实快捷方式、视觉资产、旧库升级、卸载后数据保留和统一 SHA-256。
- 加固轻量版的现有服务身份核验，避免误用其他数据目录；导出与恢复前备份使用独立文件名。
- 发布必须通过同一提交的完整 CI，并回读 Draft 附件确认字节一致；安全复核与已知构建风险见仓库内 `docs/security-review-beta.3.md`。

## 数据提醒

升级前请在设置中“导出 SQLite”，并把备份保存到另一设备或可信同步位置。不要把 `suowang.db`、备份、私人事项或未脱敏截图作为 Issue 附件。

发现问题时，请附完整安装文件名、系统版本、错误阶段和日志中的报错文本；不要发送数据库内容。
