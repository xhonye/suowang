# 所往 SUOWANG 0.2.0-beta.8

更容易安装打开，也让日常事项更简单。

- Windows 安装时可以选择创建桌面快捷方式，完成后可以直接启动所往。
- 轻量版双击图标只打开默认浏览器，不弹命令行窗口；重复打开复用已有后台。浏览器启动失败时提供本地网址与处理提示。
- 事项统一为每天可做的事项：“今天完成”记录一次，“结束事项”收进行迹，不再选择单次或持续类型。
- 事项支持私人备注，编辑过程中保留未保存的输入；下一步的开始与暂停状态更清楚。
- 桌面版可选择关闭窗口时留在托盘或退出。
- GitHub 首页精简说明，加入所往品牌图，保留驾驶舱、项目起因与早期概念图。

**Windows 推荐下载 `SUOWANG-Lite-Setup-0.2.0-beta.8.exe`。** 希望使用独立窗口可选择 Desktop Setup；Apple Silicon Mac 选择本页 DMG。

关闭轻量版网页后后台仍会运行，已保存的进度留在本机。Lite 与 Desktop 共用数据目录，请不要同时打开。

本次包含数据库升级，升级前请在设置中导出 SQLite 备份。启动时会自动创建迁移前备份。仍为未签名／未公证的公开测试版。
