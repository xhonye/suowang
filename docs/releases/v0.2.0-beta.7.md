# 所往 SUOWANG 0.2.0-beta.7

三轮体验改进后，做一次整理。

- 合并重复事项操作，清除已无作用的样式与重复项目链接。
- 轻量版也能在设置中查看当前版本；复制主线的说明更简明。
- 持续事项隔天重新可做时，可以直接选择已有事项作为下一步，不会被引导重复添加；是否开始仍由你决定。

本轮延续此前的空态起步、可见事项菜单、可靠编辑和错误重试，没有增加新的业务系统或依赖。

Windows 推荐 **SUOWANG-Lite-Setup-0.2.0-beta.7.exe**。需要独立窗口可选择 Desktop Setup，macOS Apple Silicon 使用本页 DMG。

升级不改变数据模型或备份格式。可先在设置导出 SQLite 备份；Lite 与 Desktop 共用数据目录，不能同时打开。仍为未签名／未公证的公开测试版。

同一提交经过跨平台测试、实际安装升级检查及维护者委托的 Agent 体验评估；全部附件在 Draft 中核齐并回读校验后公开。评估记录不冒认用户人工验收。
