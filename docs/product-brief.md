# 所往 SUOWANG — 当前产品简报

> **行有所往。知所往 · 择其径 · 行其事。**

## 一句话定义

SUOWANG 是人生主线驾驶舱。它让用户在认知余量不足时，看清自己所处的模式、当前主线与下一步；如果仍然难以启动，就把事项降成一个足够容易迈出的最小一步。

## 核心模型

用户只需要理解三个实体：

```text
模式 → 主线 → 事项
```

系统永久只有恢复、工作、生活三个模式。每个模式独立拥有 1–3 条进行中主线、一个当前主线指针、一个下一步指针、不归入主线的其他事项和 cue。

主线是阶段性使命，不是永久主题。多条主线可以进行中，但一个模式同一时刻只有一条当前主线。切换当前主线只改变指针，不结束旧主线，也不制造行迹。

事项可以属于某条主线，也可以作为其他事项留在模式中。每条事项由必填的事项名称和非必填的最小一步组成，并可选择为一次事项或持续事项。一次事项完成后进入行迹；持续事项每天最多记录一次，保留累计次数但继续进行中。下一步只能引用当前主线事项或其他事项；指针失效或持续事项当天已经完成时，系统依次选择当前主线第一条可做事项、其他事项第一条、空。

## 第一屏

```text
┌────────左侧栏────────┬─────────────────────────────┐
│ 驾驶舱               │ 问候              日期 · 口号 │
│ 行迹                  ├─────────────────────────────┤
│ 设置                  │ 无边框三岔大道背景 + 模式 Tab   │
│ 显示名称              │ [主线槽 1][主线槽 2][主线槽 3] │
│ 专注中 · N天          │ 当前主线详情条                 │
│ 行有所往。            │ 当前主线事项 | 其他事项 | 下一步 │
└───────────────────────┴─────────────────────────────┘
```

道路是品牌签名，也是驾驶舱上半部的连续环境背景，不使用边框、圆角或图片卡片留白。主线槽作为轻量 Dock 压住背景下沿，但不遮挡分叉与箭头。当前模式、当前主线和下一步获得明显强调，其余界面安静。

## 关键交互

- 点击主线卡立即设为当前主线。
- 主线、事项名称和最小一步原地编辑。
- 事项行显示“事项名称 ｜ 最小一步”；未填写时不显示分隔符。
- 添加事项时可选择“持续”。持续事项用轻量标签显示累计次数，末尾完成按钮只记录今天一次；右键可撤回今天、达成并结束、不再继续或删除。
- 下一步右上角的「卡住了？」会原地接管整张下一步卡片，再点即可收拢；它提供四种调整：把步幅降得更小、换一件事项、重新看看主线，或先切到恢复模式。下一步不重复显示所属主线，也不参与拖动。它调整的是步幅、动作、方向和模式，不把启动困难解释成意志问题。
- 主线卡在同模式三个槽之间拖动，空槽移动、已有槽交换。
- 事项整行拖动可以排序、改归属或设为下一步；不会跨模式。
- 主线完成或放弃时，未完成事项默认 abandoned，也可逐条移到其他事项或同模式另一主线。
- Hard delete 用于纠错，必须确认；删除主线时，所属事项默认先移到其他事项。

## 行迹和设置

行迹只按结束时间倒序展示 completed/abandoned 事实。持续事项日常记录不会制造行迹，只有明确“达成并结束”或“不再继续”后才进入行迹，并保留累计次数。行迹事项可撤回为 active；原主线仍 active 时回到原主线，否则回到同模式其他事项。行迹主线可展开，并复制为新的独立主线；新主线不复制旧事项。

设置只包含显示名称、本地头像、三个模式 cue、SQLite/JSON 导出和整库恢复。

## 技术与隐私

当前版本使用 Vanilla JS + CSS + Node 22 + SQLite，业务数据只存在本机。没有登录、云同步、远程数据库、遥测或运行时 AI。正式数据库从空人生数据开始；demo 与测试使用独立临时库。

内部数据库与 API 为兼容既有数据继续使用 `states`、`todos`、`current_mainline_id` 和 `priority_todo_id` 等稳定标识；这些实现名不进入用户界面。

## 完成闸门

- 2560×1440 和 1920×1080 下，核心驾驶信息单屏可见。
- 320px 下无关键遮挡或横向溢出。
- 重启恢复上次模式、三个槽位、当前主线、下一步和事项顺序。
- 旧数据库自动增加最小一步、事项类型与持续完成记录结构且不丢失既有事项。
- 完成事项后下一步正确接棒。
- 持续事项同一自然日最多记录一次，撤回今天和累计次数可验证。
- 每日备份、导出和覆盖恢复可验证。
- 日常使用不需要手动运行 `npm start`。
