# 所往 SUOWANG — V0.1 产品简报

> **行有所往。**

## 一句话定义

SUOWANG 是人生主线驾驶舱。它让用户在低认知余量下，3 秒内看清状态和 Current 主线，10 秒内看清当前优先。

## 核心模型

系统永久只有恢复、工作、生活三个状态。每个状态独立拥有 1–3 条进行中主线、一个 Current 指针、一个 Priority 指针、状态通用 Todo 和 cue。

主线是阶段性使命，不是永久主题。多条主线可以 active，但一个状态同一时刻只有一个 Current。切 Current 只改变指针，不结束旧主线，也不制造历史。

Todo 可以属于某条主线，也可以只属于状态。Priority 只能引用状态通用 Todo 或 Current 主线 Todo。完成、放弃或改归属使 Priority 失效时，系统按 Current 主线第一条 Todo、状态第一条 Todo、空依次补位。

## 第一屏

```text
┌────────左侧栏────────┬─────────────────────────────┐
│ 驾驶舱               │ 问候              日期 · 口号 │
│ 历史                  ├─────────────────────────────┤
│ 设置                  │ 无边框三岔大道背景 + 路线 Tab   │
│ 显示名称              │ [主线槽 1][主线槽 2][主线槽 3] │
│ 专注中 · N天          │ Current 详情条                 │
│ 行有所往。            │ 当前优先                       │
│                       │ Current Todo | 状态 Todo       │
└───────────────────────┴─────────────────────────────┘
```

道路是品牌签名，也是驾驶舱上半部的连续环境背景，不使用边框、圆角或图片卡片留白。主线槽作为轻量 Dock 压住背景下沿，但不遮挡分叉与箭头。当前状态、Current 和 Priority 获得明显强调，其余界面安静。

## 关键交互

- 点击主线卡立即设为 Current。
- 主线和 Todo 文字原地编辑。
- 主线卡在同状态三个槽之间拖动，空槽移动、已有槽交换。
- Todo 整行拖动可以排序、改归属或进入 Priority；不会跨状态。
- 主线完成或放弃时，未完成 Todo 默认 abandoned，也可逐条移到状态通用区或同状态另一主线。
- Hard delete 用于纠错，必须确认；主线 Todo 默认先移到状态通用区。

## 历史和设置

历史只按结束时间倒序展示 completed/abandoned 事实。历史主线可展开，并复制为新的独立主线；新主线不复制旧 Todo。

设置只包含显示名称、本地头像、三个 cue、SQLite/JSON 导出和整库恢复。

## 技术与隐私

V0.1 使用 Vanilla JS + CSS + Node 22 + SQLite，业务数据只存在本机。没有登录、云同步、远程数据库、遥测或运行时 AI。正式数据库从空人生数据开始；demo 与测试使用独立临时库。

## 完成闸门

- 2560×1440 和 1920×1080 下，核心驾驶信息单屏可见。
- 320px 下无关键遮挡或横向溢出。
- 重启恢复上次状态、三个槽位、Current、Priority 和 Todo 顺序。
- 完成 Todo 后 Priority 正确接棒。
- 每日备份、导出和覆盖恢复可验证。
- 日常使用不需要手动运行 `npm start`。
