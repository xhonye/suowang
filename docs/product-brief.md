# 所往 SUOWANG — V0.1 Product Brief

> **行有所往。**

## 一句话定义

所往是一款人生主线导航器。它在认知余量不足时，用稳定界面把现实状态、三条候选路径、当前主线、叙事时间线和此刻下一步连接起来。

## 品牌系统

| 层级 | 定义 |
| --- | --- |
| 品牌 | 所往 SUOWANG |
| 品牌精神 | 行有所往。 |
| 品类 | 人生主线导航器 |
| 核心机制 | 当前主线 / Mainline |
| 方法 | 知所往 · 择其径 · 行其事 |
| 传播句 | 事情很多，行有主线。 |

## 用户结果

- 3 秒内知道自己正在往哪里走。
- 10 秒内知道现在最值得做什么。
- 可以低成本查看其他可能性，但不会误触切换主线。
- 精力不足时仍有沿主线前进的更小动作。
- 数月以后能回看当时为何选择、实际发生了什么、为何切换。

## 固定信息架构

```text
┌──────────────────────────────────────────────┐
│ ① Mainline Road：三条未来路径                │
├──────────────────────────────────────────────┤
│ ② 当前主线摘要                              │
├───────────────────────────┬──────────────────┤
│ ③ 叙事时间线              │ ④ NOW            │
│ 今天 / 本周 / 本月 / 以后 │ 现在最值得做      │
└───────────────────────────┴──────────────────┘
```

信息变化时，这四层的空间关系不轻易变化。

## 三条路是什么

三条路是相互存在取舍的未来剧本，不是健康、工作、关系等领域分类。

每条路必须能说明：

- 为什么现在值得走
- 怎样算走完
- 大概要走多久
- 选择它要暂时放下什么
- 从今天到以后如何展开

## 交互底线

- 查看不等于承诺。
- `设为当前主线` 是显式、可理解的状态改变。
- 到达复盘日期只进入 `reviewing`，不自动换线。
- AI 推荐不等于用户决定。
- 计划、提醒和打开页面都不等于实际完成。

## 叙事时间线

- 今天只放一至三件具体行动。
- 本周最多三个有意义节点。
- 本月表达结果与里程碑。
- 更远处只保留方向和复盘节点。

越近越具体，越远越抽象。

## NOW 卡片

NOW 是规划的终点，至少包含：

- 一件具体事项
- 预计时长
- 所需精力
- 完成定义
- 低能量降级行动

降级行动缩小范围，但仍沿当前主线前进。

## AI 的位置

默认 UI 没有聊天框。AI 只在结构化入口出现：

- 重新评估三条路
- 解释为什么推荐
- 现实变化后重新规划时间线
- 调整现在最值得做的一步

AI 可以提议，用户负责承诺。

## 早期视觉参考的取舍

![人生主线页面早期概念图](assets/early-mainline-concept.png)

这张图用于确认产品方向，不代表当前实现状态。图中的文字、品牌标识与功能均为早期占位。

早期参考图确认了以下方向：

- 大道、地平线与三向分叉是产品识别核心。
- 三张路线卡与道路方向形成空间对应。
- 时间线和 NOW 在同一视野内完成收束。
- 蓝白、轻量、开阔的视觉气质适合“导航”而非“管理”。

参考图中的完整侧栏、通知、会员标识、复杂任务区和装饰信息不自动进入需求。最终设计以产品合同和真实可用性验证为准。

## V0.1 完成闸门

- 核心页面真实可运行。
- 三条路径、显式选择、时间线和 NOW 形成完整闭环。
- 本地状态与历史版本可恢复。
- 桌面与 320px 无关键遮挡或横向溢出。
- 键盘完成核心路径，减少动态效果设置有效。
- README 能在五秒内解释项目。
- 至少一张来自真实运行界面的截图可用于公开展示。

## 非目标

- 不做大型 Dashboard。
- 不做 Todo 或项目管理全家桶。
- 不在首页塞 AI 对话。
- 不追求打开频率、停留时间或刺激性留存。
- 不提前建设与 V0.1 主线导航无关的平台基础设施。
