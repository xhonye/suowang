# SUOWANG 0.2 alpha 反馈模板

请按真实感受简短回答。没有使用过某项可以写“没有发生”，无需为了填写完整而补操作。

1. 第一次使用时，在没有别人教学的情况下，你能否完成模式、第一条主线和下一步的设置？卡在哪里？
2. 平时打开后，你能否迅速知道现在具体该做什么？
3. “最小一步”是否真的降低了开始行动的难度？什么情况下有用或没用？
4. 恢复、工作、生活三个模式是否符合你的自然理解和切换方式？
5. “开始这一步 / 暂停”降低了行动摩擦，还是增加了操作负担？
6. 持续事项是否仍像行动记录，还是让你感觉它正在变成另一套习惯打卡？
7. 道路主视觉的高度是否妨碍你高频查看和处理事项？
8. 如果现在删除所往，你会不会感到明显损失？具体会失去什么？

反馈只需文字。请勿附带数据库、备份、导出、私人事项或未脱敏截图。SUOWANG 不采集遥测，也不会自动上传这些回答。
