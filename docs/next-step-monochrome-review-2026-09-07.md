# 下一步单色动效与控制评估

历史评估，视觉方案已被后续用户指令替代：用户明确喜欢纯蓝色粗人字箭头块，要求多个向右移动、覆盖整张卡片，并要求直接实现。本文细线预览不得作为当前实施方向；控件继续保持开始／暂停与完成、默认不计时。

用户反馈：箭头尖端像被切掉，希望单色极简、覆盖整个下一步区域、更有科技感，并评估播放、正计时、暂停等控件。

## 结论

- 现版重复 SVG 的尖端坐标接近图块右界，粗描边超出 72px 图块边界，被裁切后形成平头。原背景层仅属于 `.priority-card`，标题处于层外，所以产生上下分区。
- 建议改为单色细线斜纹，不再使用粗箭头、双色描边或渐变。背景从整张下一步卡片延展至圆角边界，覆盖标题、正文和按钮背后；文字与按钮保持静止、清楚。
- 以流动方向、固定节奏、细线和控件对齐表现科技感。卡片保持原有紧凑高度。

## 控件建议

| 控件 | 建议 | 原因 |
| --- | --- | --- |
| 播放／开始 | 在已有「开始这一步」中使用播放图标，不额外增加另一枚播放键 | 避免两个启动入口；保留中文便于理解 |
| 暂停 | 保留；开始与暂停按当前状态切换 | 能停止行动状态与动效，不代表事项结束 |
| 完成 | 保留单独按钮，持续事项仍显示「今天完成」 | 与暂停是不同语义 |
| 正计时 | 默认不加入；若用户明确希望了解本次用时，再做轻量可选项 | 打开时长不能直接视为投入时长；数字也会成为新的注意目标 |
| 倒计时、重置、进度环、统计 | 本轮不增加 | 需要新的时长目标、会话或统计模型，不服务于本轮视觉修正 |

若以后采用正计时，先确定“只累计显式开始后的本次用时”、暂停／切换模式／关闭窗口的处理与会话结束条件。不要在没有事实记录的情况下推算专注时间；当前正式模型依旧不追踪时长。
