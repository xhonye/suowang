# SUOWANG Visual Contract

## 视觉目标

界面像晴日上午直接走进一张本地导航图：阳光充足、空气清澈、地平线可见、方向明确。道路是驾驶舱上半部的环境，不是嵌在 Dashboard 里的图片组件；控件在环境之上工作，但不能把它重新框成卡片。

## Token

- `horizon #DCE9EE`：道路周围的冷雾环境。
- `fog #F2F6F5`：应用底色。
- `paper #FBFCFA`：稳定内容面。
- `asphalt #253845`：主文字与道路语义。
- `signal #4E839C`：当前状态、Current、Priority 和焦点。
- `signal-soft #DCEBF0`：选中与解释性背景。
- `ink #1B2B33`：正文。
- `muted #6C7B80`：次要信息。

中文正文使用系统内置 `Microsoft YaHei UI`，标题优先 `Segoe UI Variable Display`，日期和微型状态标签使用 `Bahnschrift`。不加载网络字体。

## 单一签名元素

当前正式页面使用一张 `2172×724` 无箭头底图与三张同画布透明箭头层：

- `mainline-scene-bright-office-v1-no-arrows-geometry-v5.png`：批准的无箭头底图
- `mainline-scene-bright-office-v1-arrow-restore-light-v2.png`：左路 / 恢复
- `mainline-scene-bright-office-v1-arrow-work-light-v4.png`：中路 / 工作
- `mainline-scene-bright-office-v1-arrow-life-light-v2.png`：右路 / 生活

状态切换只替换透明箭头层，底图、湖面、远山、阳光、天空、草地、道路、机位与裁切保持逐像素不变。背景采用 demo 版的低饱和粉蓝灰、抬高暗部和柔和对比，保持晴朗但不艳。箭头统一使用浅天空蓝，不使用白色描边或霓虹光；页面只允许与批准预览一致的轻微统一校色和用于连接工作区的短浅渐变，不能覆盖道路分叉。状态切换只做 150–250ms 的淡入。道路下方用一条细灰蓝方向线把 Current 主线槽与工作舱连接起来。大胆表达只发生在这里；其他卡片不增加装饰性漂浮动画。

`docs/visual-final-preview.html` 保留为同一套分层资产的静态视觉基准，不读取正式 SQLite。批准基座、箭头与生成溯源位于 `assets/milestones/2026-08-23-arrow-pipeline/`。

## 空间合同

桌面端左栏固定约 196px。驾驶舱不设置独立顶栏；问候、日期与口号直接浮在道路天空区域，不使用背景、边框或阴影，也不额外占据内容高度。主内容最大宽度约 1780px，大屏增加留白而非无限拉宽。

驾驶舱纵向顺序固定为道路背景舞台、主线 Dock、当前主线详情、左侧事项双栏与右侧下一步。当前主线、事项和下一步位于同一个完整工作舱内，不拆成互不相关的浮动卡片。道路背景从驾驶舱内容区左缘铺至右缘，不受主内容最大宽度约束；问候、日期、口号、标题与 Cue 都直接位于天空区域，无顶栏，随页面向下滚动自然消失。三个路线点击区即唯一的模式 Tab，整条道路都是点击目标；标题区不再重复放置第二套切换器。选中路线显示模式名称，并支持左右方向键、Home、End。主线 Dock 只轻微压住道路下沿，背景渐变与 Dock 都不能遮挡道路分叉和路线箭头。

桌面道路舞台的基准高度限制在 `430–460px`：设置中的「工作区空间」可选择小 / 中 / 大 / 最大四档，默认小。每档只通过网页展示窗口真实裁去 `0 / 28 / 50 / 72px` 顶部天空；原图不裁剪、不改写，图片和箭头层保持固定显示尺度，道路下缘画面坐标不变，主线 Dock 卡底保持低于道路下缘约 `12px` 的搭桥关系。道路分叉、箭头和模式入口必须完整。背景下沿通过浅色透明渐变进入页面底色，不使用硬边界。宁可让 Todo 少露一部分，也不能把三岔大道压成横幅。页面允许纵向滚动，Todo 长列表仍优先在各自列表内部滚动。

320px 下左栏变为底部三页导航，道路舞台约 390px 高，标题、Cue 和路线标签仍在背景中；三个主线槽改为可横向滑动的 Dock，Priority 与 Todo 垂直排列。信息阅读顺序不变，允许页面滚动，但不允许页面横向溢出。

## 克制规则

- 三状态共享一套灰蓝系统，不使用绿/蓝/橙三套主题色。
- 道路图只使用最终预览已批准的统一轻校色，不再增加雾层或额外滤镜压低道路、远景与天空的层次。
- 路线 Tab 不用整列深色蒙层表示状态；交互反馈只能是极浅的局部渐变，路线高亮由图内箭头承担。
- 道路背景不使用边框、圆角、容器阴影或外层卡片留白；它必须表现为驾驶舱所在的环境，而不是驾驶舱里的一张图。
- 不显示假统计、窗口装饰、会员徽章、通知、专注计时或励志堆叠。
- 重要状态不能只依赖颜色；Current、选中、完成和禁用均有文字或形状信号。
- 保留明显键盘焦点并尊重 `prefers-reduced-motion`。
- 空状态告诉用户下一步，不用情绪化文案填空。
