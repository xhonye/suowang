# SUOWANG 自主迭代记录

日期：2026-09-08。授权：用户委托自主观察、设计、实现、验证、体验评估和发布小版本；每三次功能迭代执行一次整理迭代。公开内容仍须经过既有构建、安全、升级和资产完整性验证。

## 起点

- 仓库为 `suowang`，分支 `main`，起始提交 `961e0fc`；远端 main 与之相同。
- 当前公开版经 GitHub 实时核对为 `0.2.0-beta.3`；没有未关闭的公开 Issue。
- 接手时已有 43 个修改或新增文件，涉及已授权的品牌精修、行动动效和 WidBar 个人试用入口。已在本次任务的工作目录逐文件备份并保存二进制 diff；保留这些内容，分开记录来源。
- 原有 102 项单元测试通过。交互观察使用独立临时数据库和 `24763` 端口；自动化沿用测试配置，不连接个人服务。
- 产品主线仍为“模式 → 主线 → 事项”，道路视觉与本地 SQLite 真源保持既有合同。

## 机会与执行顺序

| 轮次 | 现场或代码证据 | 改善目标 | 验收重点 |
| --- | --- | --- | --- |
| 1 | 无数据时下一步要求拖动不存在的事项；手机上添加入口在更下方 | 空态直接引导添加第一步；当天持续事项全部完成后安静收束 | 新用户无需先创建主线即可添加并开始；有当前主线时归入当前主线；不虚构完成事实 |
| 2（观察后决定） | 事项只有右键生命周期菜单，设下一步及移动依赖拖动 | 让触摸和键盘也能完成核心选择 | 重用既有菜单与事务；不增加业务实体；当天已完成持续事项不再推荐 |
| 3（观察后决定） | 原地编辑保存失败后整体重绘，修改内容丢失；输入法 Enter 没有组合输入保护 | 输入和保存反馈可靠 | 错误可修正并重试，中文输入不提前提交，焦点不丢失 |
| 整理 | 三轮形成的重复入口和过期表述 | 删除重复代码、收敛文档与发布记录 | 不删除用户探索档案，不扩张架构，不以无关重构拖延交付 |

每轮只在观察证据仍成立时推进。每轮完成实现、相称回归、三种尺寸体验与发行验证后发布可追溯小版本，再重新观察。候选和公开 Release 分开记录；不能用本地构建替代公开发布，也不能把 Agent 观察表述为用户人工验收。

## 停止条件

核心循环中可复现、低风险、高收益的阻碍已处理，剩余方向需要真实使用反馈或实质产品取舍时停止扩展。功能数量不是进度指标。

## 迭代结果

本地检查：102 项单元、16 项浏览器、14 项桌面单元、1 项桌面完整交互通过；实际 packaged smoke 验证数据库写入及四张批准道路解码，安全检查高风险 blocker 为 0。公开审计发现旧精修记录含本机仓库绝对路径，已改为项目名称后通过；运行时依赖审计 0 告警，构建依赖保留原有三项限时审查风险。WidBar 既有连接测试 5 项及临时服务 smoke 12 项通过，其源码保留个人试用边界。
