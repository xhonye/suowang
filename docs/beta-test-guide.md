# SUOWANG 0.2 Public Beta 使用与测试指南

这是一轮为期约两周的自然使用测试。目标不是把每个按钮点一遍，而是确认所往能否在真实生活里帮助你更快看清方向并开始行动。

## 安装前

- Windows 下载与版本号一致的 `SUOWANG-Setup-0.2.0-beta.2.exe`，或使用 Portable ZIP；安装后应直接打开独立「所往 SUOWANG」窗口，不出现 PowerShell 或浏览器地址栏。
- Apple Silicon Mac 下载 `SUOWANG-0.2.0-beta.2-mac-arm64.dmg`，拖入 Applications。首个未签名测试版可能需要按住 Control 点击应用并选择“打开”。
- 如果你已经使用过所往，先在设置中选择“导出 SQLite”，把文件保存在另一设备或可信同步位置。
- 不要发送 SQLite 数据库、备份、私人事项或个人截图来反馈问题。

## 第一次使用

1. 在恢复、工作、生活中选择此刻最贴近你的模式。
2. 建立一条真实、现阶段确实会投入时间和注意力的主线。
3. 写下至少一个事项；如果它难以开始，再补一个足够小的“最小一步”。
4. 把此刻最值得做的事项设为“下一步”。
5. 准备行动时点击“开始这一步”；临时中断就点“暂停”，真正做完再点完成。这三种操作表达不同事实。

## 持续事项

只把需要反复发生、但不需要连续打卡的行动设为持续事项，例如规律运动或按时休息。当天真实完成一次后记录一次；同一天不能重复记录。它只显示累计事实，没有连续天数、补签、积分或完成率。

## 两周自然使用

- 在你本来就会想起方向或下一步的时候打开，不必为了测试强迫自己每天签到。
- 允许真实切换模式、主线和下一步；不要为了制造数据而操作。
- 留意“开始 / 暂停”是降低摩擦还是增加仪式负担。
- 留意道路主视觉在频繁使用时是帮助定位，还是挤占了事项空间。
- 如果两周中几乎没想到打开，也请如实反馈；这本身就是重要结果。

## 备份与恢复

设置中的“导出 SQLite”是可恢复的完整副本；“导出 JSON”只便于阅读，不能恢复。应用会做本机自动备份和升级前备份，但它们通常与原数据库在同一设备，不能替代异地副本。

## 如何反馈

使用 [beta-feedback-template.md](beta-feedback-template.md) 的八个问题即可。反馈产品感受时可以只写文字；如果必须截图，请先遮住主线、事项、姓名和其他私人内容。SUOWANG 不包含遥测，也不会自动上传反馈。

## 如何报告启动故障

请提供：

- 安装文件的完整文件名与来源页面；
- 操作系统版本，以及 Windows / Apple Silicon Mac；
- 错误窗口中的阶段、原因和下一步；
- 是否出现独立应用窗口、是否意外出现终端或浏览器；开发者排查时再提供 `/health` 的 `version`（不要提供数据目录）；
- 启动日志中的报错文本。

不要发送 `suowang.db`、`backups/`、头像、SQLite/JSON 导出或包含私人事项的截图。日志若包含个人路径，可先遮盖用户名部分。
