# WidBar 0.1.1 体验优化

按用户要求不使用 Computer Use，保留任务栏 180 与卡片 340×370 的尺寸，不改业务接口或用户数据。

- 预览改为固定总宽的两列布局，图标占用明确，文字使用剩余空间；悬停可读完整模式、事项与最小一步。
- 卡片标题最多两行并保留完整提示，突出开始／暂停，底部入口固定，正文独立滚动；保存／取消只在有修改时出现。
- 草稿固定关联原事项；未保存时禁用切模式、换事项、开始及完成，保存失败或断线保留编辑；取消明确回到当前事项。

验证：独立草稿状态检查、临时服务真实错误与重试、WinUI Release 编译。未进行实际任务栏视觉验收。

结果：13 项基础检查通过，包含基础检查在内的 22 项临时服务检查通过；WinUI Release 与完整 DesktopBridge 包构建通过。备份旧松散组件后更新原注册目录并重启 WidBar，插件元数据为 0.1.1，新进程持续运行，运行目录 DLL 与发布构建一致，近期应用日志未发现组件崩溃。没有使用 Computer Use，没有修改个人事项或其它组件配置。松散包容器身份保持原样；0.1.1 为组件描述版本。
